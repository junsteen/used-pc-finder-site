# 中古PC・パーツ横断検索

複数のECサイト・中古専門店を横断し、**用途から必要スペックを判定して、部品構成と完成品を同じ土俵で比較する**ための検索サイトです。

このリポジトリは**公開用の生成物のみ**を含みます（収集処理は別の非公開リポジトリにあります）。

## 何を解決するか

既存サービスは「どの商品が安いか」「欲しい商品が出品されたか」には答えますが、**「そもそもどう買うのが正解か」**には答えていません。

- 完成品を買うべきか、部品を組み合わせるべきか
- 手持ちの部品はどの構成なら活きるか
- グレードを上下すると総額はどう動くか
- 用途が変われば答えはどう変わるか

## データソース

楽天市場・Yahoo!ショッピング・ソフマップ・ドスパラ・パソコン工房

## 免責事項

- 掲載している価格・在庫・スペックは**取得時点の情報**です。正確性・最新性を保証しません
- スペック情報の一部はAIによる調査結果で、人による検証を経ていないものが含まれます（該当分は「未検証」と表示）
- **購入判断は必ず販売元のページで最終確認のうえ、自己責任で行ってください**

## 広告について

当サイトは楽天アフィリエイトを利用しており、楽天市場の商品リンクから購入された場合に売上の一部が還元されます。
